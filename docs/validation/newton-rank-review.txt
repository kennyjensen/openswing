Reproduced an accepted-Newton-root uniqueness defect in an isolated exact copy of the current source; main remains unchanged.

Before correction: five identical scalar regression cases yield 1 failed, 4 passed (exit 1). After the minimal correction: 5 passed (exit 0). Both terminal records and logs are retained. All 58 original main Python module hashes still match; only after/openswing/time_integration.py differs between isolated copies.

The counterexample is a scalar C1 monotone residual: f(x)=1-x for x<=1/4; f(x)=u^3-1.25u^2-0.5u+0.75 for 1/4<x<3/4, u=2(x-1/4); f(x)=0 for x>=3/4. Value/slope match at each join. At x=0, f=1 and f'=-1, so a regular Newton correction lands near x=1 inside a continuum of exact roots. With check_rank=True the old accepted-correction return incorrectly accepts that point. Starting directly inside the plateau already rejects it. This distinguishes the two convergence routes without changing physics or nonlinear tolerances.

fix.patch adds the same existing regular_tangent(function,x) check and build count to the converged-correction return. Tests additionally ensure regular roots succeed at entry and after correction, and that explicit check_rank=False preserves its old behavior. The check is meaningful for both BDF and Radau, which pass this flag for inverse actuator targets, but these scalar tests are not a full solver regression or a temporal-accuracy validation. consistent_initial has its own accepted derivative-array certificate and is not changed.

Only isolated scalar checks ran; no initialization, time march, aeroelastic solve or browser workflow was duplicated. To reproduce, use a Python environment with the repository NumPy/SciPy/pytest dependencies and run test_accepted_rank.py with PYTHONPATH pointing to either before or after, one BLAS thread and external plugins disabled. run_checks.py records the exact local commands and requires fresh run directories.
