# PG geometry and straight-wing influence review

No confirmed defect was found in the audited PG transformation, lifting geometry, section normal, or Mach-zero horseshoe evaluation. This is a bounded documentation/code review; the archived SA-1 comparison remains open. [The pinned receipt](pg-review.json) retains exact source/code excerpts, line numbers, source pages, hashes and qualifications.

The source defines `xi=e/lambda`, so its scale cancels from `xi/|xi×s|`. Placing physical force and control points using unit wind before PG is source-equivalent, including sweep (steady theory pp29–33, Eqs146–161; `frozen_influence.py:14–37`). With source map `P=D R`, the code uses `Q=RᵀD R`; rotation covariance of Biot–Savart gives `Pᵀ B(P geometry)=Q B(Q geometry)`. The final velocity map is the transpose, not the inverse (`aero.py:270–277`, `factored_influence.py:151–179`). Projecting the physical section normal after that map implements the same tangency equation; no additional PG normal adjustment is required.

The independent [scalar oracle](oracle.py) replays six saved pre-stall/stalled SA-1 states at 200/400 intervals and pointwise/40-mode circulation. It retains Gamma and imports no production code or numerical packages. [Results](oracle.json) agree within 7.94e-13 m/s in velocity, 1.74e-14 in normalized local residual, 5.46e-12 N in integrated force and 8.22e-15 across reconstructed coefficients. [Six sanity checks](oracle-tests.py) pass, covering direct integration of all three Biot–Savart lines, half-wake identity, internal-filament cancellation, reflection, the two-dimensional lift-slope limit and dimensional scaling. The original temporary scripts/results are preserved and pinned in the receipt.

Two limits matter. On general curved geometry, the separately constructed interior force point need not lie on the straight bound segment, yet the code excludes the entire own bound segment. The source does not fully specify that non-collinear self-influence convention. This is an unresolved documentation boundary and is absent in straight SA-1. Separately, unsteady Eqs29–32 use a physical quarter-chord position where steady Eq155 uses a wind-shifted virtual point; their general-motion mapping is outside this stationary review.

The current bound-point Vperp in Eqs202–204 is supported by carrying the Section3.1 surface-velocity definition forward. No source basis was found for substituting control-point, beam-axis or freestream speed. Historical defaults and the aerodynamic sample-to-nodal force transfer remain qualified: the published quadrature does not prove exact historical numerical equivalence. No settings were selected by agreement, and no production file was changed.
