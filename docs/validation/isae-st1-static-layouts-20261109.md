# ST-1 additional layouts and coupled load–deflection curve

The coupled `[45/0]3s` blade now matches the archived ASWING load–deflection
curve at **all seven loads, in all three coordinates: 21/21 within 5%**.
The largest nonzero relative error is **0.0920%**. This covers one root
orientation and includes large deflection and bending–torsion coupling.
No structural equation or material property was adjusted to obtain agreement.

## Additional raw-output comparisons

Two original static models were made readable by explicitly appending `End`
to their genuinely empty trailing `Engine` blocks. No numeric input was
changed. Original files, derived files and hashes are retained. Each was
solved on nominal 100 and 200 cosine grids, with the existing exact sensor
station and the documented structural operator. Each state passes fresh
residual, clamp and independent force/moment checks, including distributed
self-weight and the tip mass.

| Layout and literal setting | Largest raw-position error, nominal 100 | Nominal 200 | Result |
|---|---:|---:|---|
| `[20/−70/−70/20]2a`, 0.7 kg, 46° twist | 0.000955% | 0.004986% | All three positions match on both meshes |
| `[45/0]3s`, 0.4 kg, 45° twist, EIcs = 0.102 N m² | 35.847% | 35.852% | All three positions disagree with the same-name text snapshot |

The 46° setting is literal: `change_mass2` adds 45° to the tabulated 1°.
The original postprocessor's last calls and mass lists support both retained
inputs: lines 461–463 for the first model and 313–315 for the second. This
does not prove that each saved text file was generated by that final call.
The same-name scripts select and write the three body-position channels.

The mesh-to-mesh position-vector changes are 7.62 and 8.37 micrometres;
the largest component changes are 0.00403% and 0.00369%, respectively.
Refinement therefore does not explain the second model's large raw-text
discrepancy. The latter's component errors are approximately 12.85%, 23.43%
and 35.85%, with median 23.43%.

## Reconciliation with the published curve

The original `[45_0]3s_theta_m45.eps` and companion PDF show the ASWING
prediction corresponding to the same producer loop. Its title says root
angle −45°; that loop writes a positive 45° ASW twist multiplier. This
orientation convention is retained, rather than changing the model's sign.

The three ASWING polylines were recovered directly from their vector
coordinates and distinct line styles. Axis calibration uses the original
numeric tick labels; every tick and every load coordinate is checked.
The companion PDF was rendered and visually checked to distinguish the
ASWING lines from experimental markers. No solver result was used to choose
the scaling, offsets or targets.

The source postprocessor subtracts each model's unloaded position, then plots
absolute displacement. Here the unloaded blade sags under its own weight;
its sensor position is approximately (−0.00733321, −0.21987416, −0.00741003) m.
Six additional cold solves cover masses 0, 0.02, 0.05, 0.1, 0.2 and 0.3 kg.
The previously checked 0.4 kg result is reused exactly.

| Coordinate | Largest nonzero curve error | Largest absolute displacement error |
|---|---:|---:|
| X | 0.00203% | 1.49 micrometres |
| Y | 0.0920% | 4.98 micrometres |
| Z | 0.00279% | 5.79 micrometres |

All 18 nonzero comparisons pass, together with the three unloaded zeros.
The acceptance includes the EPS coordinate's printed half-place and the
independently checked tick-coordinate rounding envelope. This is especially
relevant to tiny plotted values: vector export rounding is not a physical
solver discrepancy. The 5% relative allowance and numerical gates are unchanged.

The raw text and the plotted curve remain conflicting references under this
setup. Agreement with the curve supports the coupled mechanics; it does not
erase the failed text comparisons or establish their generating conditions.
Drela's steady description Eq. 18 and the moment/curvature matrix definition,
and ISAE Part III Eq. 39, support the implemented EIcs matrix placement.
The physical interpretation follows Part III §4.1, Figure 21 and Appendix A;
Table 8's column labels also contain ambiguities, so its large 298 N m² entry
is not substituted for the literal EIcs = 0.102 N m².

## Accounting and remaining work

The existing 200-slot archive view becomes **9/200 at 5%**: 12 computed
values, three mismatches and 188 unavailable values. The two nominal-100
derived-input comparisons fill six existing slots; the second meshes add no
archive votes. The full curve is a separate observable for an overlapping
physical configuration, so its 21 passing values are **not added** to 9/200.
The original strict adapter and its earlier 6/200 result remain historical
evidence; the current combined view is reproduced by the standalone scripts
linked below, not by pretending that the old literal-input adapter changed.

The next useful work is the other `[45/0]3s` root orientations, the remaining
static load curves and `[0/90]3s` input, then the report's identified bending
and torsional modes. This does not complete ST-1 or the broader structural model.

All jobs used one BLAS thread, 512 MiB address-space, 15 s CPU and 25 s wall
caps. Peak resident memory stayed below 238 MiB. The four new loaded checks
took 0.97–1.88 s after imports; the extra curve solves took 0.69–1.06 s.
An initial checker type error after a successful solve is retained separately;
it was corrected before the accepted layout comparisons. No browser/build
job ran and all 141 production modules are unchanged.
