# FW fresh-mesh verification

While preparing the remaining speed progression, inspection of the saved
equilibrium identity found that the preceding FW comparisons retained the
legacy `all-breaks-v0` mesh recipe. `warm_start_recipe` intentionally preserves
that recipe when restoring an old state with matching requested settings.
The packet has no `mesh_recipe` tag, which explicitly means the legacy recipe;
the current cold-start default is `accurate-arc-v2`.

Consequently, the preceding results use current production physics and a
freshly corrected physical equilibrium, but they do **not** verify the mesh
generated by a fresh browser solve. The previous report's description of
the setup as browser-default was incomplete. Its numerical results and
immutable receipts remain valid for their disclosed older mesh and are not
being relabeled as fresh-mesh results.

The follow-up runner
[`check_fw_current_mesh_20261114.py`](../../scripts/check_fw_current_mesh_20261114.py)
requires `accurate-arc-v2` explicitly in every accepted saved state and
matrix result. It starts the first equilibrium without a historical seed.
The reference remains literal public `fw.asw` and the published root map;
the original native ASWING mesh remains unspecified. The fresh-mesh comparison
is now complete at 64 ft/s and extended to 38 ft/s, through an intermediate
physical trim at 50 ft/s.

## Fresh-mesh results

41 structural nodes and 796 descriptor states**, versus 42 panels, 43 nodes
and 834 states in the preserved recipe. This identifies the current default
*recipe at that requested count*, not the browser's initial count setting.

The **38 ft/s R5 frequency error exceeds both the 5% target and the plotting
uncertainty**. Its full root is about −6.99191 + 1.57228i/s, so it is heavily
damped. Its combined complex distance is only 1.2392%, demonstrating why
that metric must not hide a frequency error. Next refine the current mesh
for this mode. These results alone do not establish a physical-equation bug.

## Numerical verification and remaining scope

Four small full-descriptor searches at each speed retain the algebraic
equations. Each selected mode was checked against the full nonlinear
residual along the real/imaginary parts of `(v, λv)`, at preselected
fourth-order widths 2e−4 and 4e−4. All **64/64** checks pass the same 1e−7
normalized threshold, with maximum **6.367e−11**. This includes the
unmatched real root at 64 ft/s. These checks support the matrix assembly
along those trajectories, not native Bode input/output derivatives or
every physical-model assumption.

The [root runner](../../scripts/check_fw_current_mesh_20261114.py),
[direction runner](../../scripts/check_fw_current_directions_20261114.py) and
[report generator](../../scripts/report_fw_current_mesh_20261114.py) retain
immutable runner versions and source hashes. All **22 successful
layout/solver/check jobs** completed and were reaped. Maximum CPU time was
**12.17 s**, wall time **14.80 s**, and peak RSS **101,296 KiB**. Each used
one BLAS thread and the existing 512 MiB address-space, 15 CPU-second and
25 wall-second limits. An initial layout-only job had missing constructor
arguments; it ended before correction and its failed receipt remains.
The final bounded reporting job completed, was reaped and visually inspected.

Early runner snapshots used `iterations` for the returned continuation
count. Later snapshots correct the label and retain separate equilibrium
diagnostics; accepted numerical records were not rewritten. Added shift
options select nearby roots without changing the matrices or physics.
The report verifies immutable runner versions and unchanged production
inputs separately.

Fresh-mesh coverage is **18/108 published root positions compared**: all
nine at 38 and 64 ft/s. This is coverage, not a blanket pass count. Earlier
preserved-mesh results are not added to this total. The 50 ft/s case has only
a trim comparison. Other speeds, the R5 frequency error, native mesh
identification, and FW Bode gain/phase remain open. No production physics,
aircraft file, ISAE fraction or tracked ISAE scope changed. Browser/build
checks remain on hold.
