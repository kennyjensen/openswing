# Sparse final equilibrium check

The installed solver uses a freshly assembled complete sparse final tangent for eligible mounted corrections from a saved equilibrium. Its rank check uses a conservative inverse-residual certificate, with the original full SVD as fallback. This builds on the [sparse Newton corrector](seeded-corrector.md); it does not reuse the Newton factor for final acceptance. Integration and runtime results are recorded in the [machine-readable report](final-equilibrium-rank.json).

For the saved 4,172-unknown AE-3 state, the sparse and original dense final matrices agree entry for entry, with **2,247 complete residual evaluations each**. One native comparison measured **6.868 seconds** for the certificate and **37.315 seconds** for the full SVD. Matrix assembly still took about 23 seconds in each path. These are individual phase observations, not an end-to-end browser benchmark or a measured total-memory reduction. No new large nonlinear solve or mesh refinement was performed.

The lower bound is **1.401375874994005e-9**, below the full SVD reciprocal condition estimate **7.418987018225375e-8** and above the unchanged **1e-10** acceptance threshold. The fresh complete residual is **1.424312739385853e-11**, below **1e-8**. All inverse columns are checked; no equations, unknowns or stored nonzero entries are dropped. The final sparse route has the same narrow eligibility restrictions as the saved-state Newton optimization. Other configurations and caller-provided final tangents retain their previous route.

The review also identified separate defects in the old certificate. A complex 2×2 example was incorrectly accepted with a purported bound of 1.5983e-6 although its proper dense reciprocal condition was 5.1092e-12. A float32 case raised a casting error, and noncanonical duplicate sparse storage was mutated. These observations do not establish false acceptance of a real-valued aircraft Jacobian. The replacement accepts only validated canonical real float64 CSR/CSC storage in covered numeric ranges, owns its working copy, checks inverse output shape/type, and encloses normalization and roundoff errors. Unsupported or inconclusive inputs use the full SVD. Factor/solve RuntimeError permits fallback; memory errors, interruptions and observer failures propagate.

The [arithmetic derivation](final-equilibrium-rank-proof.md) states the binary64, round-to-nearest, gradual-underflow and sparse-accumulation assumptions. The certificate bounds the mathematical reciprocal condition of the floating matrix used by the original dense-normalization path. It does not promise bit-identical acceptance to a rounded LAPACK SVD arbitrarily close to its threshold. Exact-condition metadata remains null for a certificate; its lower bound is identified separately.

Mounted saved-state progress now distinguishes final matrix assembly, rank checking and the indeterminate full-SVD fallback. Column counts describe the current check. Existing Bode-specific messages retain priority, and time-start checks do not advance accepted simulation time. Scientific gates and derivative settings are unchanged.

Native certificate tests pass **99/99**: 51 contract cases, 35 storage/cache cases and the 13 existing rank cases. Final-route tests pass **56/56**, including current/frozen influence matrix equality at the returned converged state, forced SVD fallback, final-assembly failures and callback cleanup. JavaScript formatting tests pass **10/10**. The same **99/99** certificate tests pass in actual Pyodide with local NumPy/SciPy and no network fetch. Two earlier wrapper failures occurred before any test ran: a Node Buffer archive argument and a missing pytest-owned compatibility shim. Both are retained; their fixes change no assertions or solver bytes.

The physical Pyodide check passes **29/29**, including **2,240** numeric output/state comparisons, structured Newton and injected dense recovery, and fresh residual checks. The offline browser check passes **45/45**, with **2,238** numeric comparisons, all 108 exact worker-source hashes, zero offline HTTP requests and actual rendered final-check progress. Browser evidence uses the small flexible-wing fixture and SVG fallback; it does not establish large-case browser timing, WebGL behavior, cold offline startup or the entire UI. The 32 existing equilibrium/Bode matrix-reuse WebAssembly checks also pass. Installed native verification passes 157/157 tests (the 99 certificate cases, 56 route cases and two existing static-progress cases); these are reruns, not additional unique cases. Exact tested source and UI bytes are installed locally and in the public kernel. Hosted release, runtime binaries and download distributions are unchanged.

The five earlier AE-3 mesh failures remain, and experimental setup/observable matching, driven-roll and reversal validation are unfinished. Coverage stays **17 partial / 24 pending / 0 fully validated**. No original ASWING executable is available for parity checks. This change does not complete the full project goal or establish equivalence to Drela's executable.
