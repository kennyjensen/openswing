Four rudder-response magnitudes from the current OpenSwing mesh, compared with Drela’s published ASWING drawing. This saved snapshot opens without running a solver.

Reproduce this case in Bode response

  1. In the app’s Editor, select Daedalus, then click Load checked level-flight case. This loads the trim and settings used here; selecting the aircraft alone preserves other analysis settings.
  2. Click Run analysis. Select control.3 · Rudder → Flight frame → Yaw angular velocity Ω_z · body z.
  3. Set angular response units to Degrees, frequency units to Cycles / input T (Hz for this model), and gain to Magnitude · logarithmic.

Animation versus angular rate

The app now defaults to model-time playback. For Daedalus, 1 Hz plays one cycle per second. The optional four-second phase-inspection clock changes visible turning speed and cannot be read as physical angular rate. Input amplitude scales animation, while these Bode magnitudes remain per unit input.

At 1 Hz, the checked aircraft-frame heading amplitude is 0.0119351° per F3. Its physical heading-rate amplitude is 0.0749905°/s; the plotted body yaw rate is 0.0748817°/s. The small difference comes from the Euler-angle projection.
